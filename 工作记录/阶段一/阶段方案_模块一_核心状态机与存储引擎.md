# AI-SyncForge 阶段方案：模块一 - 核心状态机与存储引擎

## 1. 模块定位
本模块是系统的绝对底层，负责所有任务状态的持久化与原子操作。该模块不涉及任何 AI 业务逻辑或网络通信，专注于数据的一致性与稳定性。

## 2. 核心开发任务

### 2.1 数据库初始化 (`database.py`)
- **存储引擎**：SQLite。
- **表结构设计**：创建 `tasks` 表，包含以下字段：
    - `id`: INTEGER PRIMARY KEY AUTOINCREMENT
    - `project_name`: TEXT
    - `code_content`: TEXT
    - `test_requirement`: TEXT
    - `task_type`: TEXT DEFAULT 'dev_test' (支持 dev_test / ops_task)
    - `priority`: INTEGER DEFAULT 0 (支持高优先级抢占，Ops 任务默认为 999)
    - `status`: TEXT DEFAULT 'pending' CHECK(status IN ('pending', 'testing', 'success', 'fail', 'fail_by_ops_intervention'))
    - `report_path`: TEXT (存储报告或故障日志路径)
    - `retry_count`: INTEGER DEFAULT 0 (用于记录重试次数)
    - `created_at`: TIMESTAMP DEFAULT CURRENT_TIMESTAMP
    - `updated_at`: TIMESTAMP DEFAULT CURRENT_TIMESTAMP
- **索引**：为 `status` 字段创建索引，以优化任务轮询效率。
- **并发模式配置**：在创建表结构之前，必须执行 `PRAGMA journal_mode=WAL;` 以开启预写式日志模式，支持更高并发的读写操作。
- **幂等性要求**：所有的建表和建触发器语句，必须使用 `CREATE TABLE IF NOT EXISTS` 和 `CREATE TRIGGER IF NOT EXISTS`，确保脚本无论运行多少次都不会因对象已存在而崩溃。
- **自动化触发器**：必须编写 SQL 创建一个 Trigger，确保任何针对 `tasks` 表的 UPDATE 操作都会自动将 `updated_at` 刷新为当前时间。

### 2.2 CRUD 接口封装
实现以下 Python 函数，确保操作的原子性与线程安全：
- **连接生命周期管理**：**禁止维持全局长连接变量**。每次调用 CRUD 函数时，必须使用上下文管理器（如 `with sqlite3.connect(..., timeout=10) as conn:`）自动管理连接的打开、提交与关闭，确保资源安全释放。
- **线程安全配置**：数据库连接配置 `check_same_thread=False`，并且在执行写操作（Insert/Update）时，需在 Python 代码层使用全局互斥锁（如 `threading.Lock()`）防止 `database is locked` 错误。
- `create_task(project, code, req, task_type='dev_test', priority=0)`: 插入新任务，支持类型指定与优先级设置。
- `update_task_status(task_id, status, report_path=None)`: 更新状态及报告路径。**特殊要求**：若传入状态代表测试失败或需要运维介入，需同时将该任务的 `retry_count` 字段加 1。
- `get_pending_task()`: **原子锁语法**。仅提取 `task_type='dev_test'` 任务，按 `priority DESC, created_at ASC` 排序。
- `poll_ops_task()`: **原子锁语法**。仅提取 `task_type='ops_task'` 任务，供运维专用。
- `get_task_by_id(task_id)`: 查询特定任务的当前详情。

### 2.3 状态机校验（单元测试）
编写 `test_database.py`，使用 `unittest` 或 `pytest` 覆盖以下场景：
- 任务创建后默认状态为 `pending`。
- `get_pending_task` 能正确提取任务并自动锁定状态为 `testing`。
- 状态转换路径验证（如 `testing` -> `success` 或 `testing` -> `fail`）。
